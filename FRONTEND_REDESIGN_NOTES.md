# Front-end redesign

This pass intentionally removes the common “AI SaaS” look: glassmorphism, neon gradients, floating cards, excessive pills, giant dashboard card grids and hackathon-facing labels in normal navigation.

## Visual direction
- Precision/editorial dark UI
- Near-black + warm ivory + acid-lime accent
- Square geometry and clear borders instead of frosted glass
- Monospace micro-labels and tighter hierarchy
- Product-first copy
- Judge Demo removed from the normal sidebar/dashboard
- Same core functionality and information architecture retained

## Deployment
Upload the contents of this ZIP to the existing GitHub repository root and commit to `main`. Vercel should redeploy automatically.
